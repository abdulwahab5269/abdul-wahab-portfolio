# Abdul Wahab Portfolio

## Goal
Build a polished, dark, single-page developer portfolio that closely follows the reference site's visual rhythm: slim sticky navigation, spacious star-field opening, bold typography, cyan/blue accents, code-inspired details, bordered content blocks, and restrained motion.

## What I’ll build
- A responsive opening section with Abdul Wahab’s identity, original introduction, profile placeholder, and project/contact actions.
- Sticky navigation with active-section indication, smooth scrolling, and an animated mobile menu.
- About, interests, skills, projects, experience, education, certifications, ACM activities, contact, and footer sections using only supplied facts.
- Editable project and certification data, with no fabricated links or achievements.
- Frontend-only contact validation with a clear success state.
- Subtle reveal, hover, timeline, and back-to-top animations with reduced-motion support.

## Visual direction
- Near-black navy background with sparse blue particles and thin indigo borders.
- White editorial headings, muted gray body copy, cyan/blue actions, and small monospace code accents.
- Wide spacing and compact, squared cards echoing the reference without copying its content or assets.
- A custom abstract profile placeholder rather than a random portrait.

## Technical details
- Implement within the existing React/TanStack project while preserving the requested standalone-style organization through clear content arrays and focused UI sections.
- Centralize colors, typography, shadows, motion, and spacing in the global design system.
- Use semantic HTML, accessible controls, keyboard-friendly navigation, and no backend.
- Add route-specific metadata for Abdul Wahab’s portfolio.

## Verification
- Test large desktop and mobile sizes.
- Check all navigation, contact/social links, hamburger behavior, form validation/success, back-to-top behavior, and horizontal overflow.
